# Which cascade stage produced each pass

Which cascade stage produced each pass

## Usage

``` r
pf_pass_stage(pass)
```

## Arguments

- pass:

  Character vector of pass names from a
  [`pf_staged_passes()`](https://nonprofit-open-data-collective.github.io/pfmatch/reference/pf_staged_passes.md)
  run.

## Value

`"A"`, `"B"`, `"C"`, or `NA`.
