# Report on a dedup run

Report on a dedup run

## Usage

``` r
pf_dedup_report(grants, n = 15)
```

## Arguments

- grants:

  Output of
  [`pf_dedup()`](https://nonprofit-open-data-collective.github.io/pfmatch/reference/pf_dedup.md).

- n:

  Number of largest clusters to show.

## Value

Invisibly, the cluster-size table. Prints a summary.
