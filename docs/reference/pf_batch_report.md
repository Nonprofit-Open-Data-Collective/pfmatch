# Summarize a batched run

Summarize a batched run

## Usage

``` r
pf_batch_report(status)
```

## Arguments

- status:

  The frame returned by
  [`pf_run_batches()`](https://nonprofit-open-data-collective.github.io/pfmatch/reference/pf_run_batches.md).

## Value

Invisibly, the outcome table. Prints a summary with throughput.
