# Match 990-PF grant recipients to the BMF

<div class="ref-description section level2">

Wraps `npmatch::np_cascade()` for the grant-recipient problem. The only
structural difference from the npmatch/SAM setup is the blocking
cascade: a foundation and its grantees need not share a state, so no
pass keys on geography.
